# GunAdder+

GunAdder+ is a Minecraft Bedrock Addon that adds a variety of realistic guns to the game. It includes popular firearms such as the AK-47, AK-15, AKM, M16, Colt M4, HK416, FN SCAR, Steyr AUG, Dragunov SVD, Glock 17, Glock 19, M1911, Beretta 92, Desert Eagle, MP5, Uzi, P90, Thompson, M2 Browning, M249 SAW, PKM, Barrett M82, and RPG-7. Each gun features unique textures and is fully functional with animations for shooting and reloading.

## Install

1. Download the GunAdder+ addon from the GitHub repository or the EnderDevelopment marketplace.
2. Place the addon file in the `addons` folder of your Minecraft Bedrock Edition world.
3. Launch Minecraft Bedrock Edition and select the world where you placed the addon.
4. The addon will be automatically loaded, and the new guns will be available in the game.

## Use

1. Open the inventory in Minecraft Bedrock Edition.
2. Find the new guns in the inventory or craft them using the provided recipes.
3. Equip the gun by selecting it from the hotbar.
4. Use the left mouse button to shoot and the right mouse button to reload the gun.
5. Enjoy the realistic gun animations and sounds.
